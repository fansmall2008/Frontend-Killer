# 日志查看器

> 页面文件：`log-viewer.html`

日志查看器页面实时显示系统运行日志，方便排查错误和监控系统状态。

---

## 页面顶部

| 元素 | 说明 |
|------|------|
| **"返回首页"** 链接 | 返回首页 |
| **"任务管理"** 链接 | 跳转到任务管理页面 |
| **🔔 通知铃铛** | 显示未读消息数量，点击打开通知面板 |

---

## 实时日志控制

| 元素 | 说明 |
|------|------|
| **显示行数** | 数字输入框，设置每次加载的日志行数（默认 100，范围 10~1000） |
| **"刷新"** 按钮 | 手动刷新日志内容 |
| **"自动刷新"** 复选框 | 勾选后每 5 秒自动加载最新日志（默认开启） |

---

## 日志内容区域

实时显示系统日志，日志按级别自动着色：

| 级别 | 颜色 | 说明 |
|------|------|------|
| **ERROR** | 🔴 红色 | 错误信息，需要关注 |
| **WARN** | 🟡 黄色 | 警告信息，可能存在问题 |
| **INFO** | 🔵 青色 | 一般信息，正常运行记录 |
| **DEBUG** | 🟢 绿色 | 调试信息，详细运行数据 |

日志内容区域最大高度 600px，超出后可滚动查看。

---

## 通知系统

与系统设置页面相同的通知功能：

| 元素 | 说明 |
|------|------|
| **通知铃铛 🔔** | 右上角固定显示，红色角标显示未读数 |
| **通知弹窗** | 右上角弹出通知，3 秒后自动消失 |
| **通知面板** | 点击铃铛打开的模态框，显示历史消息 |
