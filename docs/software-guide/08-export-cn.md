# 导出平台

> 页面文件：`export.html`

导出平台页面用于将游戏平台数据导出为指定前端格式的配置文件、ROM 文件和媒体文件。

---

## 流程概览

```mermaid
flowchart LR
    A[选择平台] --> B[选择前端模板]
    B --> C[配置导出选项]
    C --> D[设置导出路径]
    D --> E[执行导出]
    E --> F[后台任务执行]
```

## 导出表单

### 选择平台

| 字段 | 说明 |
|------|------|
| **选择平台** | 下拉选择要导出的平台，格式为"系统名 (平台名)" |

### 选择前端

| 字段 | 说明 |
|------|------|
| **选择前端** | 下拉选择目标前端模板 |
| **前端描述** | 选中后显示该前端的详细说明（数据文件格式、路径格式等） |
| **模板限制提示** | 如果模板不支持某些导出内容，显示黄色警告 |

支持的前端模板：

| 前端 | 数据文件格式 | 路径格式 |
|------|-------------|----------|
| **Pegasus** | metadata.pegasus.txt | 相对路径（不带 ./ 前缀） |
| **ES-DE** | gamelist.xml | 标准相对路径（带 ./ 前缀） |
| **RetroBat** | gamelist.xml | 标准相对路径（带 ./ 前缀） |
| **EmuELEC** | gamelist.xml | 支持三种查找位置 |
| **Lakka** | gamelist.xml + .lpl | 支持核心映射 |
| **Pegasus V3** | metadata.pegasus.txt (V3) | V3 格式 |
| **ES-DE V3** | gamelist.xml (V3) | V3 格式 |
| **RetroBat V3** | gamelist.xml (V3) | V3 格式 |
| **EmuELEC V3** | gamelist.xml (V3) | V3 格式 |

### 导出范围

| 选项 | 说明 |
|------|------|
| **游戏文件** | 复制 ROM 文件到导出目录（部分模板可能禁用此选项） |
| **媒体文件** | 复制媒体文件到导出目录（部分模板可能禁用此选项） |
| **数据文件** | 生成前端数据文件（gamelist.xml / metadata.pegasus.txt 等） |

> 💡 某些前端模板限制了可导出的内容类型，被限制的选项会自动禁用并显示警告。

### 导出路径

| 字段 | 说明 |
|------|------|
| **导出路径** | 导出目标路径，默认为 `/output` |

### 线程数

| 字段 | 说明 |
|------|------|
| **线程数** | 导出使用的并行线程数，默认 4，最高 10 |

## 操作按钮

| 按钮 | 说明 |
|------|------|
| **"导出"** | 提交导出任务（提交后按钮变为加载状态） |
| **"返回首页"** | 返回首页 |

---

## 导出过程

1. 提交后，导出任务作为后台任务执行
2. 页面右上角弹出通知提示任务已启动
3. 可在 [任务管理](12-task-management-cn.md) 页面查看进度
4. 任务完成后会弹出通知
