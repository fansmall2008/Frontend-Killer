# 系统设置

> 页面文件：`system-settings.html`

系统设置页面用于配置系统参数，包括语言、ScreenScraper 凭据、游戏列表展示、数据库备份等。

---

## 页面顶部

| 元素 | 说明 |
|------|------|
| **"返回首页"** 按钮 | 返回首页 |
| **🔔 通知铃铛** | 显示未读任务消息数量，点击打开通知面板 |

---

## 语言设置

| 元素 | 说明 |
|------|------|
| **选择语言** | 下拉选择：中文 / English / 日本語 |

> 💡 语言设置保存后页面刷新生效。

---

## ScreenScraper 设置

| 字段 | 说明 |
|------|------|
| **用户名** | ScreenScraper 账号用户名 |
| **密码** | ScreenScraper 账号密码 |

| 按钮 | 说明 |
|------|------|
| **"保存设置"** | 保存 ScreenScraper 凭据 |
| **"测试连接"** | 测试当前凭据是否能正常连接 ScreenScraper API |
| **"获取系统列表"** | 从 ScreenScraper 拉取所有系统数据并导入数据库（需确认） |

> 💡 不填写用户名密码将使用游客模式（每日约 20,000 次请求限制）。如需更高限额，请在 [ScreenScraper.fr](https://www.screenscraper.fr/) 注册账号。

---

## 游戏列表展示设置

| 字段 | 说明 |
|------|------|
| **游戏列表图标字段** | 下拉选择游戏列表中显示的图标媒体类型 |

可选的图标类型（共 21 种）：

| 选项 | 说明 |
|------|------|
| **封面图 (image)** | 默认选项 |
| **轮盘图标 (wheel)** | 转盘 Logo |
| **轮盘图标-碳 (wheel-carbon)** | 碳纤风格转盘 |
| **轮盘图标-钢 (wheel-steel)** | 钢质风格转盘 |
| **Logo (logo)** | 通用 Logo |
| **缩略图 (thumbnail)** | 缩略图 |
| **包装盒正面 (box-2D)** | 2D 包装盒正面 |
| **包装盒背面 (box-2D-back)** | 2D 包装盒背面 |
| **3D包装盒 (box-3D)** | 3D 立体包装盒 |
| **包装盒侧面 (box-2D-side)** | 2D 包装盒侧面 |
| **横幅图 (banner)** | 横幅图片 |
| **标题画面 (sstitle)** | 标题截图 |
| **截图 (ss)** | 游戏截图 |
| **粉丝艺术图 (fanart)** | 同人画 |
| **海报 (poster)** | 海报图 |
| **卡带图 (support-2D)** | 2D 卡带/介质图 |
| **边框图 (bezel)** | 屏幕边框 |
| **面板图 (panel)** | 控制面板图 |
| **背景图 (background)** | 背景图 |
| **Steam图 (steam)** | Steam 风格图 |
| **Steam网格图 (steamgrid)** | Steam Grid 图 |

| 按钮 | 说明 |
|------|------|
| **"保存设置"** | 保存图标显示设置（存储在浏览器本地，刷新页面生效） |

> 💡 如果某个游戏没有该类型的媒体文件，图标位置将显示空白。

---

## 数据库备份

| 按钮 | 说明 |
|------|------|
| **"备份数据库"** | 将当前数据库导出为 SQL 备份文件 |
| **"恢复数据库"** | 从备份文件恢复数据库（需选择备份文件） |
| **"执行初始化"** | 重建表结构并清空所有数据（⚠️ 不可逆操作） |

### 备份文件列表

显示所有已有的数据库备份文件，每个备份文件旁有"恢复数据库"按钮。

---

## 通知系统

| 元素 | 说明 |
|------|------|
| **通知铃铛 🔔** | 固定显示在页面右上角，红色角标显示未读消息数 |
| **通知弹窗** | 右上角弹出的彩色通知条，3 秒后自动消失 |
| **通知面板** | 点击铃铛打开的模态框，显示所有历史任务消息 |
