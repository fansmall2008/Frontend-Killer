# 首页

> 页面文件：`index.html`

首页是应用的导航中心，提供 5 个功能卡片入口和系统状态概览。

---

├──────────┼──────────┼───────────────┤

## 功能卡片

### 1. 导入

- **链接目标**：`data-import.html`
- **功能说明**：扫描 ROM 目录，按模板导入游戏数据
- **详见**：[数据导入](03-data-import-cn.md)

### 2. 数据处理

- **链接目标**：`platform-management.html`
- **功能说明**：管理平台列表、编辑游戏数据、执行刮削
- **详见**：[平台管理](04-platform-mgmt-cn.md)

### 3. 数据合并

- **链接目标**：`platform-merge.html`
- **功能说明**：将多个平台合并为一个新平台
- **详见**：[平台合并](07-platform-merge-cn.md)

### 4. 导出

- **链接目标**：`export.html`
- **功能说明**：按前端模板导出游戏列表和媒体文件
- **详见**：[数据导出](08-export-cn.md)

### 5. 系统设置及数据

此卡片包含多个子入口：

| 子卡片 | 链接目标 | 说明 |
|--------|----------|------|
| 系统设置 | `system-settings.html` | 语言、SS 账号、数据库管理 |
| 刮削系统管理 | `scraper-system-list.html` | 管理 ScreenScraper 系统数据 |
| 媒体下载管理 | `media-download.html` | 查看和控制媒体下载任务 |
| H2 数据库控制台 | `/h2-console` | 直接查询 H2 数据库 |
| 后台任务管理 | `task-management.html` | 查看后台任务状态和日志 |

## 通知铃铛 🔔

- **位置**：页面右上角
- **功能**：点击展开通知面板，显示最近的任务消息
- **角标**：红色数字表示未读消息数量
- **关闭**：点击模态框中的 × 按钮或点击模态框外部关闭

---

## 刮削环境检查

首次进入首页时，系统会自动检查：

1. **ScreenScraper 账号** 是否已配置
2. **刮削系统数据** 是否已初始化

如果任一条件不满足，会弹出警告框：

| 按钮 | 功能 |
|------|------|
| **"前往配置"** | 跳转到系统设置页面配置 SS 账号 |
| **"我知道了"** | 关闭警告，继续使用 |

> 💡 即使不配置 SS 账号也可以使用，但刮削将以游客模式运行，每日请求限额较低。
