# 任务管理

> 页面文件：`task-management.html`

任务管理页面实时监控所有后台任务的执行状态，包括导出、刮削、导入等任务。

---

## 页面顶部

| 元素 | 说明 |
|------|------|
| **"返回首页"** 按钮 | 返回首页 |
| **"日志查看器"** 按钮 | 跳转到日志查看器页面 |

---

## 任务列表

### 任务卡片

每个任务显示为一张卡片，包含以下信息：

| 元素 | 说明 |
|------|------|
| **任务描述** | 任务名称或类型描述 |
| **状态标签** | RUNNING（青）/ COMPLETED（绿）/ FAILED（红）/ PENDING（黄） |
| **开始时间** | 任务开始执行的时间 |
| **结束时间** | 任务完成/失败的时间（未完成时不显示） |
| **进度条** | 可视化显示任务完成百分比 |
| **进度百分比** | 当前完成百分比 |
| **状态消息** | 任务的当前状态描述 |
| **处理进度** | 已处理数 / 总数（仅处理中的任务显示） |
| **错误信息** | 任务失败时的错误详情（仅失败时显示） |
| **结果信息** | 任务完成后的结果摘要（仅完成时显示） |
| **详细日志** | 可展开/收起的任务执行日志 |

### 任务操作

| 按钮 | 说明 |
|------|------|
| **"删除"** | 删除该任务记录 |
| **"清空所有任务"** | 删除所有任务记录（需确认） |
| **"展开/收起"** | 展开或收起任务的详细日志 |

---

## 媒体下载任务面板

当存在刮削任务时，页面顶部显示媒体下载任务的汇总信息：

| 元素 | 说明 |
|------|------|
| **总数量** | 媒体下载任务总数 |
| **已完成** | 下载完成的数量（绿色） |
| **失败** | 下载失败的数量（红色） |
| **待处理** | 等待下载的数量（黄色） |
| **下载中** | 正在下载的数量（蓝色） |
| **进度条** | 可视化显示下载完成百分比 |

| 按钮 | 说明 |
|------|------|
| **"开始下载"** | 启动媒体下载任务 |
| **"停止下载"** | 停止正在进行的媒体下载 |

---

## 自动刷新

- 任务列表每 **5 秒**自动刷新一次
- 媒体下载状态每 **3 秒**刷新一次
- 任务状态变化时自动弹出通知（完成/失败）
- 检测到刮削限额警告时显示醒目通知

---

## 跨页面通知

任务管理页面通过 BroadcastChannel 向其他打开的页面广播任务完成/失败通知，确保用户在任何页面都能及时获知任务状态变化。
