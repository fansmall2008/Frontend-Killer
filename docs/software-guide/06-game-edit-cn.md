# 游戏编辑

> 页面文件：`game-edit.html`

游戏编辑页面用于修改单条游戏的元数据、管理媒体文件、从 ScreenScraper 检索补充数据。

---

## 页面顶部

| 元素 | 说明 |
|------|------|
| **"← 返回列表"** 按钮 | 返回游戏列表页面 |
| **游戏名称** | 显示当前编辑的游戏名称 |
| **"检索游戏"** 按钮 | 打开 ScreenScraper 搜索模态框 |

---

## Tab 导航

页面使用 4 个选项卡组织内容：

| 选项卡 | 说明 |
|--------|------|
| **基本信息** | 游戏核心字段编辑 |
| **元数据** | 系统级元数据（ID、CRC32、来源等） |
| **媒体管理** | 按分类管理 50 种媒体类型的上传/删除 |
| **媒体预览** | 画廊模式预览所有已有媒体文件 |

---

## Tab 1：基本信息

| 字段 | 说明 |
|------|------|
| **游戏名称 (name)** | 游戏原始名称 |
| **游戏路径 (path)** | ROM 文件路径 |
| **游戏描述 (desc)** | 游戏描述文本 |
| **翻译名称 (translatedName)** | 翻译后的游戏名 |
| **翻译描述 (translatedDesc)** | 翻译后的描述 |
| **开发商 (developer)** | 游戏开发商 |
| **发行商 (publisher)** | 游戏发行商 |
| **游戏类型 (genre)** | 游戏类型 |
| **玩家数 (players)** | 支持的玩家数 |
| **发布日期 (releasedate)** | 发行日期 |
| **评分 (rating)** | 游戏评分 |
| **语言 (lang)** | 游戏语言 |
| **游戏文件名 (filename)** | 只读，从路径提取的文件名 |
| **平台路径 (platformPath)** | 所属平台路径 |
| **绝对路径 (absolutePath)** | ROM 文件绝对路径 |

### 切换译文按钮

| 按钮 | 说明 |
|------|------|
| **"🔄 切换译文"** | 将原文名称/描述与译文名称/描述互换 |

---

## Tab 2：元数据

| 字段 | 说明 |
|------|------|
| **游戏 ID (gameId)** | 只读，ScreenScraper 游戏 ID |
| **来源 (source)** | 数据来源 |
| **CRC32 (crc32)** | 只读，ROM 文件 CRC32 校验值 |
| **类型 ID (genreid)** | 只读，ScreenScraper 类型 ID |
| **平台 ID (platformId)** | 只读，所属平台 ID |
| **平台路径 (platformPath)** | 所属平台路径 |
| **排序字段 (sortBy)** | 游戏排序依据字段 |

---

## Tab 3：媒体管理

按分类显示 50 种媒体类型，每种类型一张卡片：

### 媒体分类

| 分类 | 包含类型 |
|------|----------|
| 📦 包装盒 (Elements Boitiers) | 2D 封面、2D 背面、2D 侧面 |
| 🎁 立体盒 (Boitiers) | 3D 盒、盒贴图 |
| 📋 扫描源 (Sources) | 盒扫描 |
| 💿 介质 (Supports) | 2D 介质、介质贴图 |
| 🔍 介质扫描 (Supports-scan) | 介质扫描 |
| 🎯 Logo (Wheels) | 转盘、HD 转盘、碳纤转盘、钢质转盘等 |
| 💡 Marquee | 跑马灯、屏幕跑马灯 |
| 🖼️ 媒体 (Médias) | 截图、标题截图、Steam Grid、同人画、视频等 |
| 🖥️ 边框 (Bezels) | 4:3/16:9 各方向边框 |
| 📄 次要媒体 | 传单、手册、地图、手办 |
| 🎨 混图 (Mixes) | mixrbv1、mixrbv2 |
| 🎭 主题 (Themes) | 主屏主题、横屏主题 |
| 🎰 Pinball 媒体 | DMD、正面、桌面、顶部视频等 |
| 🗃️ 次要图片 | 背景、列表图标、彩色图标、单色图标 |

### 每张媒体卡片

| 元素 | 说明 |
|------|------|
| **媒体类型名称** | 显示当前媒体类型的名称 |
| **预览区域** | 显示已有文件预览（图片/视频）或空状态 |
| **"上传"** 按钮 | 选择本地文件上传到该媒体类型 |
| **"删除"** 按钮 | 删除该媒体类型的已有文件（仅文件存在时显示） |

---

## Tab 4：媒体预览

画廊模式展示当前游戏所有已有媒体文件：

- 图片类型：直接显示缩略图
- 视频类型：显示视频播放器
- 其他类型：显示"查看/下载文件"链接

---

## 底部操作栏

| 按钮 | 说明 |
|------|------|
| **"保存修改"** | 保存当前所有编辑的字段 |
| **"检索游戏"** | 打开 ScreenScraper 搜索模态框 |
| **"取消"** | 返回游戏列表 |

---

## 检索游戏模态框

| 元素 | 说明 |
|------|------|
| **搜索输入框** | 输入游戏名称，按 Enter 或点击搜索 |
| **"搜索"** 按钮 | 执行 ScreenScraper API 搜索 |
| **"☁️ 顺手下载媒体文件"** 复选框 | 选中搜索结果后自动下载对应媒体到本地 |
| **搜索结果列表** | 显示匹配的游戏，含缩略图、年份、类型、玩家数、评分、开发商、发行商 |

### 搜索结果操作

点击搜索结果后：

1. **自动回填**：将搜索结果的名称、描述、开发商、发行商、类型、玩家数、年份、评分填入编辑表单
2. **媒体下载**（如勾选）：将搜索结果中的媒体文件加入下载队列
