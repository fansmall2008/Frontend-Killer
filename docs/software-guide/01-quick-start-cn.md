# 快速开始

> 从零到导出的最小操作步骤，适合首次使用者。

---

## 前提条件

1. **Java 17+** 已安装（或 Docker 环境）
2. **ROM 文件** 已准备好（目录结构不限）
3. （推荐）注册 [ScreenScraper](https://www.screenscraper.fr/) 账号以获取更高 API 配额

---

## 第一步：启动应用

### JAR 方式

```bash
java -jar webGamelistOper-1.2.jar
```

### Docker 方式

```bash
docker compose up -d
```

启动后浏览器访问 **http://localhost:8080**，看到首页 5 个功能卡片即表示启动成功。

---

## 第二步：配置 ScreenScraper（可选但推荐）

1. 点击首页 **"系统设置及数据"** 卡片 → **"系统设置"**
2. 在 **ScreenScraper 设置** 区域输入用户名和密码
3. 点击 **"保存设置"**
4. 点击 **"测试连接"** 确认连接成功
5. 点击 **"获取系统列表"** 初始化刮削系统数据

> 💡 不配置也可使用，但将以游客模式运行，每日请求限额约 200 次。

---

## 第三步：导入 ROM 数据

1. 点击首页 **"导入"** 卡片，进入数据导入页面
2. **扫描路径**：输入或浏览选择 ROM 文件所在目录
3. **扫描深度**：选择"全部"或指定层数
4. **选择系统**（可选）：选择对应的刮削系统，可自动关联文件扩展名
5. **导入模板**：选择与你的 ROM 目录结构匹配的模板
6. 勾选 **"匹配无记录媒体文件"**（推荐）
7. 点击 **"开始扫描并导入"**

> 导入完成后，页面会显示导入结果统计。

---

## 第四步：创建平台并刮削

1. 返回首页 → 点击 **"数据处理"** 卡片（即平台管理）
2. 点击 **"新增平台"**，填写平台名称、路径等基本信息
3. 在平台列表中找到新平台，点击 **"编辑"**
4. 在编辑弹窗中 **选择刮削系统**（与 ROM 对应的游戏主机）
5. 保存后，点击平台行中的 **"刮削"** 按钮
6. 在刮削弹窗中确认设置，点击 **"开始刮削"**

> 刮削过程在后台执行，可在 **"任务管理"** 页面查看进度。

---

## 第五步：编辑游戏（可选）

1. 在平台管理中点击平台名称，进入 **游戏列表**
2. 点击任意游戏行进入 **游戏编辑** 页面
3. 修改名称、描述、翻译等信息
4. 点击 **"检索游戏"** 可从 ScreenScraper 搜索补充数据
5. 编辑完成后点击 **"保存修改"**

---

## 第六步：导出数据

1. 返回首页 → 点击 **"导出"** 卡片
2. **选择平台**：选择要导出的平台
3. **选择前端**：选择目标前端格式（如 Pegasus、ES-DE 等）
4. **导出范围**：勾选需要的内容（游戏文件 / 媒体文件 / 数据文件）
5. **导出路径**：指定输出目录
6. 点击 **"导出"**

> 导出完成后，到指定目录查看生成的 gamelist.xml 和媒体文件。

---

## 最小流程速查

```
启动 JAR → 配置 SS 账号 → 导入 ROM → 新增平台 → 刮削 → (编辑) → 导出
```

| 步骤 | 页面 | 核心按钮 |
|------|------|----------|
| 启动 | — | `java -jar` |
| 配置 | 系统设置 | 保存设置 / 测试连接 / 获取系统列表 |
| 导入 | 数据导入 | 开始扫描并导入 |
| 建平台 | 平台管理 | 新增平台 → 编辑 → 选刮削系统 |
| 刮削 | 平台管理 | 刮削按钮 |
| 编辑 | 游戏编辑 | 保存修改 / 检索游戏 |
| 导出 | 数据导出 | 导出 |
