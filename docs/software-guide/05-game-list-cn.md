# 游戏列表

> 页面文件：`game-list.html`

游戏列表页面展示某个平台下的所有游戏，支持搜索、分页、批量操作等功能。

---

## 页面顶部

| 元素 | 说明 |
|------|------|
| **"返回平台管理"** 按钮 | 返回平台管理页面 |
| **平台名称** | 显示当前平台名称 |
| **"搜索"** 按钮 | 展开/收起搜索区域 |
| **游戏总数** | 显示当前平台的游戏总数 |

---

## 搜索区域

点击 **"搜索"** 按钮展开/收起，包含以下筛选条件：

| 字段 | 类型 | 说明 |
|------|------|------|
| **关键词搜索** | 文本输入 | 搜索游戏名称或路径 |
| **发行日期范围** | 年份范围 | 开始年份 ~ 结束年份 |
| **开发商** | 复选框列表 | 动态加载该平台所有开发商，可多选 |
| **游戏类型** | 复选框列表 | 动态加载所有类型，可多选 |
| **玩家数量** | 复选框列表 | 动态加载所有玩家数，可多选 |
| **刮削状态** | 复选框列表 | 完全刮削 / 部分刮削 / 未刮削 |
| **文件状态** | 复选框列表 | 文件存在 / 文件不存在 |
| **文件夹路径** | 文本输入 | 按文件夹名称过滤（支持任意层级匹配） |

| 按钮 | 说明 |
|------|------|
| **"搜索"** | 执行搜索 |
| **"重置"** | 清除所有搜索条件 |

---

## 工具栏

位于分页控件区域左侧：

| 元素 | 类型 | 说明 |
|------|------|------|
| **每页显示** | 下拉选择 | 每页显示条数：20 / 50 / 100 |
| **"新增"** 按钮 | 工具栏按钮 | 弹出新增游戏模态框 |
| **"删除选中"** 按钮 | 工具栏按钮 | 删除勾选的游戏（需先勾选） |
| **"批量刮削"** 按钮 | 工具栏按钮 | 对勾选的游戏执行批量刮削 |
| **"合盘"** 按钮 | 工具栏按钮 | 将勾选的多光盘游戏合并为单条记录 |
| **"批量修改"** 按钮 | 工具栏按钮 | 批量修改勾选游戏的开发商/发行商/类型等 |
| **"翻译"** 按钮 | 工具栏按钮 | 对勾选的游戏执行翻译 |
| **"迁转"** 按钮 | 工具栏按钮 | 将勾选的游戏迁移到其他平台 |
| **"切换译文"** 按钮 | 工具栏按钮 | 交换勾选游戏的原文与译文 |

> 💡 除"新增"外，所有批量操作按钮需先勾选游戏行才可点击。

---

## 分页控件

位于工具栏右侧：

| 元素 | 说明 |
|------|------|
| **"上一页"** 按钮 | 翻到上一页 |
| **页码信息** | 显示"第 X 页，共 Y 页" |
| **"下一页"** 按钮 | 翻到下一页 |

---

## 状态图例

表格上方显示颜色含义说明：

| 颜色 | 含义 |
|------|------|
| 🔴 红色 | 无信息 — 游戏缺少关键元数据 |
| 🟡 黄色 | 部分缺失 — 游戏有部分元数据但不完整 |
| 🟢 绿色 | 信息完整 — 游戏元数据完整 |

---

## 游戏表格

| 列名 | 说明 |
|------|------|
| **☑** | 全选/单选复选框 |
| **状态** | 红/黄/绿圆点表示数据完整度 |
| **ID** | 游戏数据库 ID |
| **图标** | 配置的图标字段缩略图（可在系统设置中配置显示哪种媒体类型） |
| **游戏名称** | 游戏名 |
| **游戏路径** | ROM 文件路径 |
| **平台路径** | 所属平台路径 |
| **游戏描述** | 游戏描述文本 |
| **翻译名称** | 翻译后的游戏名 |
| **翻译描述** | 翻译后的描述 |
| **开发商** | 游戏开发商 |
| **发行商** | 游戏发行商 |
| **游戏类型** | 游戏类型 |
| **玩家数量** | 支持的玩家数 |
| **发行日期** | 发行日期 |
| **评分** | 游戏评分 |
| **语言** | 游戏语言 |
| **文件状态** | ROM 文件是否存在 |

**行操作**：点击任意游戏行可进入 [游戏编辑](06-game-edit-cn.md) 页面。

---

## 批量编辑模态框

点击 **"批量修改"** 按钮弹出：

| 字段 | 说明 |
|------|------|
| **开发商** | 留空则不修改 |
| **发行商** | 留空则不修改 |
| **游戏类型** | 留空则不修改 |
| **玩家数** | 留空则不修改 |
| **语言** | 留空则不修改 |

| 按钮 | 说明 |
|------|------|
| **"确认修改"** | 对所有勾选的游戏应用修改 |
| **"取消"** | 关闭弹窗 |

---

## 批量刮削模态框

点击 **"批量刮削"** 按钮弹出，配置与平台管理中的刮削模态框相同：

- 刮削范围、游戏信息字段、媒体文件类型、语种标签

---

## 新增游戏模态框

点击 **"新增"** 按钮弹出，填写游戏基本信息后创建新记录。
