# 刮削系统

> 相关页面：`scraper-system-list.html`、`scraper-system-edit.html`

刮削系统页面用于管理 ScreenScraper 支持的游戏主机/掌机/街机系统列表，为数据刮削提供系统映射基础。

---

## 系统列表页

> 页面文件：`scraper-system-list.html`

### 页面顶部

| 元素 | 说明 |
|------|------|
| **"返回首页"** 按钮 | 返回首页 |

### 工具栏

| 按钮 | 说明 |
|------|------|
| **"添加系统"** | 打开系统编辑页添加新系统 |
| **"初始化系统"** | 从 ScreenScraper API 拉取所有系统数据并导入 |
| **"清空全部"** | 删除所有已配置的系统记录 |

### 系统表格

| 列名 | 说明 |
|------|------|
| **ID** | 数据库记录 ID |
| **系统 ID** | ScreenScraper 分配的系统编号 |
| **名称** | 系统名称（法语原文） |
| **英文名** | 系统英文名称 |
| **制造商** | 系统制造商（如 Nintendo、Sony、Sega） |
| **类型** | 系统类型（如 console、arcade、handheld） |
| **发行年份** | 系统发行年份 |
| **媒体状态** | 该系统各媒体类型的可用状态 |

### 每行操作

| 按钮 | 说明 |
|------|------|
| **"编辑"** | 进入系统编辑页修改该系统信息 |
| **"刮削"** | 对该系统下的所有游戏执行媒体刮削 |
| **"删除"** | 删除该系统记录 |

### 刮削模态框

点击"刮削"按钮后弹出，确认对该系统所有媒体文件执行刮削：

| 元素 | 说明 |
|------|------|
| **确认信息** | 显示将要刮削的系统名称和媒体范围 |
| **"确认"** 按钮 | 开始刮削任务 |
| **"取消"** 按钮 | 关闭弹窗 |

### 分页

每页显示 20 条记录。

## 系统编辑页

> 页面文件：`scraper-system-edit.html`

用于添加或编辑刮削系统信息。

### 页面顶部

| 元素 | 说明 |
|------|------|
| **"← 返回系统列表"** 链接 | 返回系统列表页 |
| **页面标题** | 添加时显示"添加刮削系统"，编辑时显示"编辑刮削系统" |

### 表单字段

| 字段 | 必填 | 说明 |
|------|------|------|
| **系统 ID (systemId)** | ✅ | ScreenScraper 分配的系统编号 |
| **类型 (type)** | | 系统类型，如 console、arcade、handheld |
| **名称 (name)** | ✅ | 系统名称（法语原文） |

### 多语言名称

| 字段 | 说明 |
|------|------|
| **英文名称 (nameEn)** | 系统英文名 |
| **法语名称 (nameFr)** | 系统法语名 |
| **日语名称 (nameJp)** | 系统日语名 |
| **中文名称 (nameCn)** | 系统中文名 |

### 其他字段

| 字段 | 说明 |
|------|------|
| **制造商 (company)** | 系统制造商，如 Nintendo、Sony、Sega |
| **发行年份 (releaseYear)** | 系统发行年份 |
| **图标 URL (iconUrl)** | 系统图标链接 |

### 操作按钮

| 按钮 | 说明 |
|------|------|
| **"取消"** | 返回系统列表 |
| **"保存"** | 保存系统信息（保存成功后自动返回列表） |
