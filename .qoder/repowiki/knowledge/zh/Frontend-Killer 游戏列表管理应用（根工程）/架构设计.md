根工程是 Frontend-Killer 应用的 Maven 聚合入口（pom.xml 定义 artifactId webGamelistOper、主类 com.gamelist.Application），通过 Spring Boot 启动内嵌 Tomcat 暴露 HTTP 服务；数据层使用 H2（开发/默认）或 MySQL（生产），由 Flyway 在启动时执行 database/ 下的迁移脚本完成建表；静态资源（HTML/JS/CSS/i18n）与规则文件（rules/import、rules/export）通过 SPRING_RESOURCES_STATIC_LOCATIONS 挂载到 /data、/data/roms、/data/output、/data/input 等目录，配合 entrypoint.sh 与 docker-compose.yml 实现容器化运行；根目录还包含 Python 修复脚本（fix_genres.py、fix_media_types.py、fix_roms.py 等）用于批量修正 ROM 元数据，以及 build.bat/build-distribution.bat 等多平台构建脚本，将 src/ 编译产物与 docs/wiki 等资源一并打包为可分发 JAR/Docker 镜像。
