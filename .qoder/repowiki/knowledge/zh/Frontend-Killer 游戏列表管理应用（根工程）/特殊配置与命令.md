构建：mvn package（Spring Boot Maven Plugin repackage 生成可执行 jar，主类 com.gamelist.Application）；本地运行：java -jar target/webGamelistOper-*.jar 或双击 start.bat；容器运行：docker run 或 docker-compose up -d，需挂载 data/rules/export、data/rules/import、output、logs、backup 卷并设置 SPRING_PROFILES_ACTIVE=default、SERVER_TOMCAT_BASEDIR=/data、SPRING_RESOURCES_STATIC_LOCATIONS 环境变量。
