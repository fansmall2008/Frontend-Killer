# 使用指南：数据处理流水线

本指南以**数据流水线**为核心，介绍如何从获取数据到导出的完整流程。

---

## 📥 阶段一：获取数据

### 1.1 导入游戏的三种方式

本软件支持三种导入游戏的方式，您可以根据实际情况选择最适合的方式。

#### 方式一：传统方式扫描

**支持格式**：Pegasus、gamelist.xml

**媒体文件匹配**：采用写死的规则进行匹配

**特点**：速度较慢，规则固定

---

#### 方式二：通过 JSON 模板扫描（推荐）

**支持格式**：支持多种平台的自定义模板

**媒体文件匹配**：采用模板规定的匹配方式，灵活可配置

**特点**：
- 较为灵活
- 模板可自定义编写
- 支持复杂的匹配规则

> 📎 [导入模板说明文件链接](Template-Guide)

---

#### 方式三：无数据文件导入

**适用场景**：没有数据文件的游戏集合

**媒体文件**：可通过模板规则匹配媒体文件

**缺点**：因为没有数据文件，只能导入游戏名等基本信息

---

注意导入游戏集合时无需创建游戏平台，导入动作会自动创建游戏平台。

## 🔧 阶段二：数据加工

### 2.1 编辑游戏信息

#### 平台编辑

**建议操作**：导入平台后，首先点击平台名称更改平台信息。

**平台操作功能**：

| 功能 | 说明 |
|------|------|
| 查看 | 查看平台详情和游戏列表 |
| 编辑 | 修改平台名称、路径等信息 |
| 删除 | 删除平台及其所有游戏（谨慎操作） |
| 翻译 | 翻译**整个平台的游戏信息**（非平台自身信息） |
| 分离 | 将平台按规则分离为新平台或游戏子集 |

---

#### 分离功能详解

**作用**：将当前平台的游戏按条件分离出来

**分离方式**：
1. **分离为新平台**：创建独立的新平台
2. **分离为游戏子集**：创建临时的游戏子集

> ⚠️ **注意**：分离操作**不会删除原平台游戏**，仅复制一份要分离的游戏。

**游戏子集功能**：
- 可在子集中任意编辑游戏数据
- 编辑完成后，可将数据同步回原平台
- 适合在不影响原数据的情况下进行测试和加工

---

#### 翻译功能

**说明**：用于翻译平台内所有游戏的信息（如名称、描述等）

**注意事项**：
- 翻译范围：平台内的所有游戏数据
- 需要先配置翻译 API 设置
- 具体配置方法请参见 [翻译 API 设置](Translation-API-Settings)

### 2.2 补充媒体文件（功能未开发）



### 2.3 数据清洗

**删除无效数据**：
1. 筛选出无效游戏（如文件不存在）
2. 勾选并删除

**数据规范化**：
- 使用搜索功能查找重复游戏
- 统一游戏命名格式
- 补充缺失信息

### 2.4 翻译游戏信息

**批量翻译**：
1. 勾选需要翻译的游戏
2. 点击「批量翻译」
3. 选择目标语言
4. 点击「开始翻译」

---

## 📤 阶段三：数据导出

### 3.1 选择导出模板

根据目标设备选择合适的模板：

| 模板 | 适用设备 | 说明 |
|------|---------|------|
| ES-DE | PC/Linux | 功能最全，支持多种媒体 |
| Pegasus | 多平台 | 轻量级跨平台 |
| RetroBat | Windows | 集成 RetroArch |
| Lakka | 嵌入式 | 精简游戏机系统 |
| EmuELEC | 嵌入式 | 多模拟器支持 |

### 3.2 配置导出选项

1. 点击左侧菜单「导出」
2. **选择平台**：勾选要导出的平台（可多选）
3. **选择模板**：从下拉菜单选择目标前端
4. **设置输出路径**：指定导出目录
5. **选择导出内容**：
   - ✅ 游戏列表文件（gamelist.xml）
   - ✅ 媒体文件（封面、截图、视频）
   - ⬜ ROM 文件（如需）
6. **高级设置**：
   - 线程数（影响导出速度）
   - 媒体类型过滤（只导出需要的类型）

### 3.3 执行导出

1. 点击「开始导出」
2. 查看导出进度
3. 导出完成后：
   - 确认文件完整性
   - 检查导出日志


---

## ⚙️ 阶段四：软件设置


### 4.1 数据备份

1. 进入「系统设置」→「数据备份」
2. **备份**：备份现有游戏数据
3. **恢复**：恢复备份的游戏数据
4. **初始化**：初始化数据库


### 4.2 语言设置

1. 使用下拉菜单
2. 选择目标语言（中文/English）
3. 页面会自动刷新

---

## 🔄 完整流水线示例

```
获取数据 → 数据加工 → 数据导出 → 部署
     ↓           ↓           ↓
 扫描游戏    编辑信息    选择模板
 导入列表    添加封面    设置路径
 手动添加    批量翻译    执行导出
```
