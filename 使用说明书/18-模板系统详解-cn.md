# 18 · 模板系统详解

> 导入/导出时，软件靠"模板规则"决定每个字段怎么取值、文件叫什么名、放到哪个目录。模板里可以写**表达式**——引用字段、拼接字符串、调用函数。本章是模板系统的完整参考：变量、运算符、全部 21 个内置函数、配方示例与排错。

**适用场景**：编辑导入规则（`rules/import/`）、导出规则（`rules/export/`）里的字段映射、文件名、路径模板时。

---

## 18.1 先分清"字段名"和"表达式"

模板里填的值分两种：

- **纯字段名**：如 `name`、`desc`、`box-2D`。直接取这个游戏字段的值，不做任何加工。
- **表达式**：只要包含**函数调用括号 `()`**、**加号 `+`**、**`or` 运算符**（前后带空格）、或**以引号开头**，就被当成表达式来计算。

例：
- `name` → 纯字段，取游戏名。
- `name or filename` → 表达式（有 or），名字为空时退回文件名。
- `stem(path) + ".jpg"` → 表达式（有函数和 +），取文件名去扩展名再接 `.jpg`。

**字符串字面量**用双引号或单引号包裹：`"hello"`、`'.jpg'`。

## 18.3 运算符

只有两个运算符，**优先级从低到高**：

| 运算符 | 含义 | 优先级 |
|---|---|---|
| `or` | **回退**——取第一个非空值（类似 SQL COALESCE） | 低 |
| `+` | **字符串拼接** | 高 |

因为 `+` 优先级高于 `or`，所以：

- `name or filename + ".jpg"` 等价于 `name or (filename + ".jpg")`——name 有值就用 name（不加 .jpg），否则用 filename+".jpg"。
- 想让两者都带后缀，要加括号：`(name or filename) + ".jpg"`。

`or` 关键字**前后必须有空格**（或位于首尾），否则不会当运算符——这样 `color`、`order` 这类含 "or" 的字段名不会被误判。

多级回退示例：`box-2D or screenshot or image`（依次找第一个有的媒体）。

## 18.4 全部 21 个内置函数

按类别列出。参数里 `str`/`path` 表示会先求值的表达式。

### A. 字符串操作（11 个）

| 函数 | 签名 | 说明 |
|---|---|---|
| `sub` | `sub(str, start[, end])` | 截取子串。start 从 0 开始；省略 end 截到末尾。越界自动裁剪 |
| `upper` | `upper(str)` | 转大写 |
| `lower` | `lower(str)` | 转小写 |
| `trim` | `trim(str)` | 去首尾空白 |
| `replace` | `replace(str, from, to)` | 把 from 全部替换成 to |
| `before` | `before(str, sep)` | 取分隔符**之前**部分；没有分隔符则返回原串 |
| `after` | `after(str, sep)` | 取分隔符**之后**部分；没有分隔符则返回原串 |
| `concat` | `concat(f1, f2, ...)` | 拼接所有参数，**跳过空值** |
| `sanitize` | `sanitize(str, charset)` | 把 charset 里出现的每个字符替换成 `_`（用于清理非法文件名字符） |
| `matches` | `matches(str, regex)` | 正则**全匹配**，返回 `"true"`/`"false"` |
| `len` | `len(str)` | 返回字符串长度（数字字符串） |

示例：
- `sub(name, 0, 7)` → 取名字前 7 个字符。
- `upper(stem(path))` → 文件名（去扩展名）转大写。
- `trim(replace(name, " ", "_"))` → 空格换下划线再去首尾空白（可嵌套）。
- `before(name, "(")` → 取第一个 `(` 之前的部分（常用于去掉 "(USA)" 这类后缀前）。
- `after(path, "/")` → 取第一个 `/` 之后。
- `sanitize(name, "<>\"/\\|?*")` → 把 Windows 非法文件名字符全换成 `_`。
- `if(matches(genre, ".*Racing.*"), "竞速", "其他")` → 配合 if 做条件。

### B. 路径操作（4 个）

| 函数 | 签名 | 说明 |
|---|---|---|
| `filename` | `filename(path)` | 从路径取**文件名（含扩展名）** |
| `stem` | `stem(path)` | 取文件名并**去掉扩展名** |
| `ext` | `ext(path)` | 取**扩展名（含点）**，如 `.zip`；无扩展名返回空 |
| `dir` | `dir(path)` | 取**目录部分**（父路径） |

示例：`stem(path) + ext(path)` 还原完整文件名；`dir(path)` 拿所在目录。

> 注意区分：路径函数 `filename(path)` 返回**含扩展名**的文件名；而计算字段 `filename`（不带括号）返回**不含扩展名**的文件名。两者不同，别混。

### C. 条件 / 默认值（3 个，惰性求值）

| 函数 | 签名 | 说明 |
|---|---|---|
| `default` | `default(field, fallback)` | field 为空时用 fallback |
| `if` | `if(cond, trueVal[, falseVal])` | cond 非空且不为 `"false"` 视为真，返回 trueVal，否则 falseVal |
| `coalesce` | `coalesce(f1, f2, ...)` | 返回第一个非空值（等价于 `or` 链的函数写法） |

这三个是**惰性求值**：只计算用得到的分支，避免不必要的开销/报错。

示例：
- `default(desc, "暂无简介")`。
- `if(multiFile, m3uPath, filename(path))` → 多文件用 m3u 名，否则用文件名。
- `coalesce(translatedName, name, filename)` → 优先译名，其次原名，最后文件名。

> `if` 的真假约定：字符串 `"false"`（不分大小写）和空串算假，其它非空算真——正好对接 `matches` 的返回值。

### D. 日期操作（1 个）

| 函数 | 签名 | 说明 |
|---|---|---|
| `dateformat` | `dateformat(dateStr, pattern)` | 把日期按 pattern 重新格式化 |

- 能自动识别多种输入格式：`yyyy-MM-dd'T'HH:mm:ss`、`yyyy-MM-dd HH:mm:ss`、`yyyy-MM-dd`、`yyyyMMdd`、`yyyy`、`MM/dd/yyyy`、`dd/MM/yyyy`。
- 解析不出来时**原样返回**输入，不会报错。
- pattern 用 Java `SimpleDateFormat` 语法（`yyyy` 年、`MM` 月、`dd` 日）。

示例：`dateformat(releasedate, "yyyy")` → 只取年份；`dateformat(releasedate, "yyyy-MM")`。

### E. 方言映射（2 个）

用于把 ScreenScraper 的原始词（英文 genre、系统名等）映射成你想要的本地化/自定义词。映射表在 `term_mapping`（`rules/translation-config.json` 等维护），分 `genre`、`system_alias` 等分类。

| 函数 | 签名 | 说明 |
|---|---|---|
| `map` | `map(value[, category])` | 查映射表命中返回目标词，**未命中原样返回** |
| `mapFirst` | `mapFirst(value[, category])` | 同上，但多值时**只返回第一个**映射结果 |

规则细节：
- 不指定 category：在**除 `system_alias` 外**的所有分类里查（system_alias 是系统匹配内部用途）；同一值命中多个分类时按分类名字典序取第一个（保证结果确定）。
- 指定 category：只在该分类查，如 `map(genre, "genre")`。
- 查表前对值做**归一化**（小写、去空白和标点），所以 `"Beat'em Up"` / `"beat em up"` / `"beatemup"` 等价。
- **多值处理**（值里含逗号，如 `"Racing, Driving"`）：
  - `map`：逐段映射，用 `-` 连接所有结果。
  - `mapFirst`：先试整体映射，不行再拆分取第一个有效结果——适合目录名等只要单一值的场景。

示例：`map(genre)` 把英文类型转中文；`mapFirst(genre)` 只要主类型。

## 18.5 综合配方示例

**文件名（安全化）**
```
sanitize(stem(path), "<>\"/\\|?*")
```
去扩展名 + 清理非法字符，得到可安全用作文件名的字符串。

**媒体多级回退 + 后缀**
```
(box-2D or screenshot or image) + ".png"
```

**导出目录按平台/年份分层**
```
platform.name + "/" + dateformat(releasedate, "yyyy") + "/" + name
```

**类型本地化**
```
map(genre, "genre")
```

**多文件游戏特殊处理**
```
if(multiFile, m3uPath, filename(path))
```

**名字带括号后缀时取主名**
```
trim(before(name, "("))
```

**空值兜底**
```
coalesce(translatedName, name, filename, "未知游戏")
```

## 18.6 常见错误与排查

| 现象 | 原因 | 解决 |
|---|---|---|
| 表达式原样输出/取不到值 | 该写表达式却缺了触发条件（没有 `()`/`+`/`or`/引号），被当纯字段名 | 检查是否漏了函数括号或引号 |
| `or` 没生效 | `or` 前后没空格，或字段名里本身含 "or" | `or` 两侧留空格 |
| 拼接和回退结果不符预期 | `+` 优先级高于 `or` | 用括号明确顺序 `(a or b) + ".ext"` |
| `filename` 结果不对 | 混淆了函数 `filename(path)`（含扩展名）和字段 `filename`（不含扩展名） | 按需选择；想去扩展名用 `stem` |
| `map` 没映射成功 | 值未归一化命中 / 分类不对 / 表里没这条 | 确认 `term_mapping` 有对应条目；必要时指定 category |
| `dateformat` 原样返回 | 输入日期格式不在可识别列表 | 先规整日期格式，或换 pattern |
| 表达式整体失败返回空 | 语法错误（括号/引号不配对等），引擎会记 warn 日志并返回 null | 去日志查看器看 "表达式计算失败" 的 warn（见 `16`） |

> 引擎对表达式求值失败是**容错**的：不抛错，只记一条 warn 日志并返回空值。所以某字段莫名变空时，先去日志看有没有表达式告警。

## 18.7 与导入导出的关系

- **导入规则**（`rules/import/`）：定义怎么从数据文件读字段填进游戏。
- **导出规则**（`rules/export/`）：定义导出时文件名、目录、数据文件字段怎么生成。
- 不同前端（Pegasus、EmulationStation 等）有各自的模板限制，导出页会有黄色提示（见 `10`）。

模板表达式是这些规则的"计算内核"，导入导出共用同一套引擎，语法完全一致。
