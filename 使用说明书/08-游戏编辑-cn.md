# 08 · 游戏编辑

> 游戏编辑页用来精修**单个游戏**的资料：改文字信息、管理媒体、手动从 ScreenScraper 找数据、预览效果。当自动刮削不够准时，就靠这里手动补。

**入口**：游戏列表 → 点某个游戏（详见 `07`）

---

## 8.1 四个标签页（Tab）

游戏编辑页顶部有 4 个标签，点切换：

| 标签 | 作用 |
|---|---|
| **基本信息** | 名称、描述、发行商、开发者、发行日期、类型、玩家数、评分、路径等核心字段 |
| **元数据** | 更完整的元数据字段（含各类标识、扩展信息） |
| **媒体管理** | 管理这个游戏的图片/视频等媒体（关联、替换、查看 50 种媒体类型） |
| **媒体预览** | 直接预览已有的媒体效果 |

---

## 8.2 基本信息 / 元数据

在这两个标签里，你可以直接编辑游戏的各项字段：

- **名称 / 排序名**：游戏显示名，以及用于排序的名称。
- **描述**：游戏简介。
- **发行商 / 开发者**：出品方。
- **发行日期**：支持多种日期格式。
- **类型（genre）**：游戏类型。
- **玩家数 / 评分**：人数与评级。
- **路径**：游戏 ROM 文件路径。

> 💡 **保存时的智能检查**：如果你改了路径，保存时软件会检查这个路径指向的**文件是否真实存在**，并更新"文件存在"状态。如果文件不在，可能只改了名字也能保存，但会被标记为"文件不存在"，界面上可能给出提示。

改完点 **保存更改**。

---

## 8.3 手动检索游戏（自动刮削没匹配上时）

有时自动刮削找不到某个游戏，或找错了。这时用 **"搜索游戏"** 功能手动来：

1. 在游戏编辑页点"搜索游戏"，打开检索模态框。
2. 输入关键词，从 ScreenScraper 查候选结果。
3. 从候选里选中正确的那个游戏。
4. 把它的资料和媒体应用到当前游戏。

这适合处理那些冷门、名字特殊、或自动匹配失败的游戏。（这也是一种"自动没搞定就手动兜底"的思路。）

---

## 8.4 媒体管理

**媒体管理**标签里，你可以管理这个游戏关联的所有媒体。ScreenScraper 定义了多达 **50 种媒体类型**，常见的有：

| 类型（nomcourt） | 含义 |
|---|---|
| `box-2D` | 平面封面（正/背/侧） |
| `box-3D` | 立体盒图 |
| `ss` | 游戏截图 |
| `video` | 游戏视频 |
| `wheel` / `wheel-carbon` / `wheel-steel` | 游戏标志（logo） |
| `marquee` | 街机灯箱图 |
| `fanart` | 背景艺术图 |
| `manuel` | 手册（文档） |
| `mixrbv1` / `mixrbv2` | 混合图 |
| `bezel-*` | 边框装饰图 |
| …… | 其余共 50 种 |

在媒体管理里你可以查看当前游戏有哪些媒体、缺哪些，并进行关联或调整。

> 媒体文件的批量下载在 **媒体下载** 页做（见 `12`），这里主要针对单个游戏查看和精修。

---

## 8.5 媒体预览

**媒体预览**标签直接把游戏的图片/视频显示出来，让你确认媒体对不对、好不好看，不用去文件夹里翻。

---

## 8.6 批量编辑（回到列表做）

如果要一次改很多游戏的同一字段，不用一个个进来——回到**游戏列表**勾选多个游戏，用"批量修改"更快（见 `07`）。游戏编辑页专注于**单个游戏的精细处理**。

---

## 8.7 典型用法

- 自动刮削把发行日期弄错了 → 进基本信息手动改 → 保存。
- 某个冷门游戏没刮到 → 用"搜索游戏"手动找 → 应用。
- 想确认封面截图对不对 → 媒体预览看一眼。
- ROM 挪了位置 → 改路径 → 保存（软件会检查文件是否存在）。
