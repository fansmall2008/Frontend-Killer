# 17 · システム設定とパーソナライズ

> システム設定はソフトウェアの「コントロールパネル」です：言語、テーマ、効果音、スクレイピングアカウント、キャッシュ方針、リストの外観、そして最も重要な——データベースのバックアップ／復元／初期化がすべてここにあります。本章では各ブロックを説明し、特に元に戻せない危険な操作を明示します。

**入口**：サイドバー **システム設定** ⚙️（SYSTEM グループ）

---

## 17.1 画面の概要

システム設定画面は上から順にいくつかのブロックに分かれます：

1. 言語設定
2. 🎨 テーマパック設定
3. 🔊 効果音設定
4. ScreenScraper 設定
5. ゲーム情報キャッシュ
6. ゲームリスト表示設定
7. データベースバックアップ ⚠️（初期化の危険操作を含む）

以下でブロックごとに説明します。

---

## 17.2 言語設定

- **言語の選択**：中文 / English / 日本語 の三択。
- 切替後は**ページを再読み込みして初めて反映**されます（画面に案内あり）。
- サイト全体の文言は統一された i18n 機構で、三言語をカバーします。

> トップバーからも素早く言語を切り替えられます（`03` 参照）。

---

## 17.3 テーマパック設定 🎨

- 画面は利用可能なテーマパックを**カードグリッド**で表示し、クリックで切替。
- 1 つのテーマパックは画面の**配色・フォント・効果音**を同時に変えます。
- テーマファイルは `data/themes/` ディレクトリに置かれます（カスタムテーマも置けます）。

---

## 17.4 効果音設定 🔊

- **画面効果音を有効化**：マスタースイッチ。
- **マスター音量**：スライダー 0 ~ 100、既定 50%。
- **各イベントの効果音**：イベントごとのオン／オフ、**クリックで試聴**可能。
- 効果音は既定で **Web Audio API 合成**を使い、オーディオファイル不要。カスタムテーマはテーマディレクトリに mp3/wav を置けます。

---

## 17.5 ScreenScraper 設定（スクレイピングアカウント）

これはスクレイピング機能が正常に動くかの**重要な前提**です（`11` 参照）：

| コントロール | 説明 |
|---|---|
| **ユーザー名 / パスワード** | あなたの ScreenScraper アカウント |
| **設定を保存** | アカウントを保存 |
| **接続テスト** | アカウントが使えるか検証 |
| **システム一覧の取得** | ScreenScraper のシステム一覧を取得（プラットフォームのシステムバインドに必要） |

> **ゲストモード**：アカウントなしでも使えますが、1 日約 **20000 回**のリクエスト制限があり、上限に達しやすいです。安定したスクレイピングとより高い制限が欲しいなら、[ScreenScraper.fr](https://www.screenscraper.fr/) で無料でアカウント登録して入力することを推奨します。
>
> ホームには環境セルフチェックがあり、アカウントやシステムデータが欠けていると「スクレイパー準備未完」警告を出してここに誘導します（`05` 参照）。

---

## 17.6 ゲーム情報キャッシュ（アーケードのみ）

- **ゲーム情報を自動キャッシュ**チェックボックスは、**既定でオフ**。
- オンにすると：スクレイピングに成功した**アーケード**ゲームは ScreenScraper が返した完全情報をローカルにキャッシュし、エクスポート時にそれに基づいて**親 ROM を自動で揃え**られます（clone 依存）。
- ⚠️ コスト：**リクエスト割り当てを一部消費**します。アーケードを遊び、親子 ROM 関係を処理する必要があるときのみ推奨。

> ソフトウェアの初回実行時に一度だけ、これを有効にするか尋ねるダイアログが出ます（`03`、「誘導ノード整理」E3/N23 参照）。そのとき決めきれなくても、後でここに来て変更できます。

---

## 17.7 ゲームリスト表示設定

- **ゲームリストのアイコンフィールド**：ゲームリストの各行にどの画像を表示するかを決めます。選択肢は多く（約 20 種）、よく使うものは：

  | 選択肢 | 意味 |
  |---|---|
  | カバー画像 (image) | 既定のカバー |
  | ホイールアイコン (wheel / wheel-carbon / wheel-steel) | ゲームロゴ |
  | ボックス (box-2D / box-2D-back / box-3D / box-2D-side) | ボックス表／裏／立体／側面 |
  | スクリーンショット (ss) / タイトル画面 (sstitle) | ゲーム画面 |
  | バナー (banner) / ポスター (poster) / ファンアート (fanart) | 宣伝画像 |
  | その他 | logo、thumbnail、bezel、panel、steam、steamgrid など |

- 設定後は**ページを再読み込みして反映**されます。
- ⚠️ 注意：あるゲームに**選択したタイプのメディアファイルがない**場合、アイコン欄は**空白**になります。だから wheel を選んだのに wheel をダウンロードしていないと、一面空白になります。

---

## 17.8 データベースバックアップ ⚠️（重点、危険操作を含む）

このブロックはデータ安全を管理し、3 つのボタンは結果が大きく異なります：

| ボタン | 作用 | リスク |
|---|---|---|
| **データベースをバックアップ** | 現在のデータをまとめてバックアップ（下のバックアップ一覧で選択／管理） | 🟢 安全、頻繁に推奨 |
| **データベースを復元** | あるバックアップで現在のデータを**上書き**（既存テーブルを削除してからインポート） | 🟠 高——現在のデータが置換される |
| **初期化を実行** | **テーブル構造を再構築し全データを消去** | 🔴 極高——**元に戻せない**、全データが消える |

画面には明確に記載されています：

> データベース初期化を実行すると、テーブル構造を再構築し全データを消去します。**この操作は元に戻せません。慎重に実行してください！**

**利用の推奨**：
- リスクのある大きな操作の前（プラットフォーム統合、一括削除、復元、初期化）には、**まず「データベースをバックアップ」を押す**。
- **復元**前によく考える：バックアップで現在のデータを上書きするので、バックアップより新しい変更は失われます。
- **初期化**はほぼ「出荷時リセット」に等しく、本当に消してやり直したいときのみ使い、**必ず先にバックアップ**してください。

> これら 3 つの操作（特に初期化／復元）は記録済みの高優先度誘導ポイントです（「誘導ノード整理」N20）：将来、誤クリック防止のため確認を強化（確認語の入力など）するかもしれません。

---

## 17.9 代表的な使い方

- **初めて使う**：ScreenScraper アカウントを入力 → 接続テスト → システム一覧の取得（スクレイピングの前提）。
- **気分を変えたい**：テーマパックを切替 / 効果音を調整 / リストアイコンフィールドを変更。
- **大きな動作の前**：まずデータベースをバックアップ。
- **失敗して戻したい**：バックアップ一覧から復元（まずバックアップが欲しい版か確認）。
- **多言語ユーザー**：言語を切替 → 再読み込み。
