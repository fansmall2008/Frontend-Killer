# 08 · ゲーム編集

> ゲーム編集画面は**単一ゲーム**の資料を精緻に仕上げるためのものです：文字情報の変更、メディア管理、ScreenScraper から手動でデータを探す、効果のプレビュー。自動スクレイピングが正確でないとき、ここで手動補完します。

**入口**：ゲームリスト → あるゲームをクリック（詳述 `07`）

---

## 8.1 4 つのタブ（Tab）

ゲーム編集画面上部に 4 つのタブがあり、クリックで切り替えます：

| タブ | 役割 |
|---|---|
| **基本情報** | 名前、説明、発売元、開発元、発売日、ジャンル、プレイヤー数、評価、パスなどのコアフィールド |
| **メタデータ** | より完全なメタデータフィールド（各種識別子、拡張情報を含む） |
| **メディア管理** | このゲームの画像／動画などのメディアを管理（関連付け、置換、50 種のメディアタイプの確認） |
| **メディアプレビュー** | 既存メディアの効果を直接プレビュー |

---

## 8.2 基本情報 / メタデータ

この 2 つのタブで、ゲームの各フィールドを直接編集できます：

- **名前 / 並び替え名**：ゲームの表示名、および並び替え用の名前。
- **説明**：ゲームの紹介文。
- **発売元 / 開発元**：製作側。
- **発売日**：複数の日付形式に対応。
- **ジャンル（genre）**：ゲームジャンル。
- **プレイヤー数 / 評価**：人数とレーティング。
- **パス**：ゲーム ROM ファイルのパス。

> 💡 **保存時のスマートチェック**：パスを変更した場合、保存時にソフトウェアはそのパスが指す**ファイルが実在するか**をチェックし、「ファイルの有無」状態を更新します。ファイルがない場合、名前だけ変えても保存できることがありますが、「ファイルなし」とマークされ、画面にプロンプトが出ることがあります。

変更後 **変更を保存** をクリック。

---

## 8.3 手動でゲーム検索（自動スクレイピングがマッチしないとき）

自動スクレイピングがあるゲームを見つけられない、または間違えることがあります。そのときは **"ゲーム検索"** 機能で手動で行います：

1. ゲーム編集画面で「ゲーム検索」を押し、検索モーダルを開く。
2. キーワードを入力し、ScreenScraper から候補を検索。
3. 候補から正しいゲームを選ぶ。
4. その資料とメディアを現在のゲームに適用。

これはマイナーなゲーム、名前が特殊なゲーム、自動マッチに失敗したゲームの処理に適します（「自動で駄目なら手動でフォールバック」という考え方でもあります）。

---

## 8.4 メディア管理

**メディア管理**タブで、このゲームに関連付けられたすべてのメディアを管理できます。ScreenScraper は最大 **50 種のメディアタイプ**を定義しており、よく使うものは：

| タイプ（nomcourt） | 意味 |
|---|---|
| `box-2D` | 平面カバー（表／裏／側面） |
| `box-3D` | 立体ボックス画像 |
| `ss` | ゲームのスクリーンショット |
| `video` | ゲームの動画 |
| `wheel` / `wheel-carbon` / `wheel-steel` | ゲームロゴ（logo） |
| `marquee` | アーケードのマーキー画像 |
| `fanart` | 背景アート画像 |
| `manuel` | マニュアル（ドキュメント） |
| `mixrbv1` / `mixrbv2` | ミックス画像 |
| `bezel-*` | ベゼル装飾画像 |
| …… | その他計 50 種 |

メディア管理では、現在のゲームにどのメディアがあり何が欠けているかを確認し、関連付けや調整を行えます。

> メディアファイルの一括ダウンロードは **メディアダウンロード** 画面で行います（`12` 参照）。ここでは主に単一ゲームの確認と仕上げをします。

---

## 8.5 メディアプレビュー

**メディアプレビュー**タブはゲームの画像／動画を直接表示し、メディアが正しいか・見栄えが良いかを確認できます。フォルダを漁る必要はありません。

---

## 8.6 一括編集（リストに戻って行う）

多くのゲームの同一フィールドを一度に変えたい場合、一つずつ入る必要はありません——**ゲームリスト**に戻って複数ゲームをチェックし、「一括変更」を使う方が速いです（`07` 参照）。ゲーム編集画面は**単一ゲームの精密処理**に集中します。

---

## 8.7 代表的な使い方

- 自動スクレイピングが発売日を間違えた → 基本情報に入り手動で修正 → 保存。
- あるマイナーなゲームがスクレイピングされなかった → 「ゲーム検索」で手動で探す → 適用。
- カバーやスクリーンショットが正しいか確認したい → メディアプレビューで一目。
- ROM を移動した → パスを変更 → 保存（ソフトウェアがファイルの実在をチェック）。

---

## 8.8 次のステップ

- 大量のデータ補完はスクレイピングで → `11 自動スクレイピング`
- メディアの一括ダウンロード → `12 メディアファイル管理`
- 50 種のメディアタイプとフィールド命名の対照 → `18 テンプレートシステム詳解`
