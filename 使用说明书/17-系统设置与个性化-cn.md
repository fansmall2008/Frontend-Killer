# 17 · 系统设置与个性化

> 系统设置是软件的"控制台"：语言、主题、音效、刮削账号、缓存策略、列表外观，以及最重要的——数据库备份/恢复/初始化都在这里。本章逐块讲清楚，尤其标出不可逆的危险操作。

**入口**：侧边栏 **系统设置** ⚙️（SYSTEM 分组）

---

## 17.1 页面总览

系统设置页从上到下分成几块：

1. 语言设置
2. 🎨 主题包设置
3. 🔊 音效设置
4. ScreenScraper 设置
5. 游戏信息缓存
6. 游戏列表展示设置
7. 数据库备份 ⚠️（含初始化危险操作）

下面逐块说明。

---

## 17.2 语言设置

- **选择语言**：中文 / English / 日本語 三选一。
- 切换后**需刷新页面才生效**（页面有提示）。
- 全站文案走统一的 i18n 机制，三语覆盖。

> 也可在顶部栏快速切换语言（见 `03`）。

---

## 17.3 主题包设置 🎨

- 页面以**卡片网格**展示可用主题包，点选即可切换。
- 一个主题包会同时改变界面的**配色、字体和音效**。
- 主题文件存放在 `data/themes/` 目录下（可放自定义主题）。

---

## 17.4 音效设置 🔊

- **启用界面音效**：总开关。
- **主音量**：滑块 0 ~ 100，默认 50%。
- **各事件音效**：逐个事件的开关，**点击可试听**。
- 音效默认用 **Web Audio API 合成**，无需音频文件；自定义主题可放 mp3/wav 到主题目录。

---

## 17.5 ScreenScraper 设置（刮削账号）

这是刮削功能能否正常工作的**关键前提**（见 `11`）：

| 控件 | 说明 |
|---|---|
| **用户名 / 密码** | 你的 ScreenScraper 账号 |
| **保存设置** | 保存账号 |
| **测试连接** | 验证账号是否可用 |
| **获取系统列表** | 拉取 ScreenScraper 的系统清单（平台绑定系统要用） |

> **游客模式**：不填账号也能用，但每天约 **20000 次**请求限制，容易触顶。想稳定刮削、更高限额，建议去 [ScreenScraper.fr](https://www.screenscraper.fr/) 免费注册账号后填进来。
>
> 首页有环境自检：账号或系统数据缺失时会弹"刮削器未就绪"警告并引导你来这里配置（见 `05`）。

---

## 17.6 游戏信息缓存（仅街机）

- **自动缓存游戏信息**勾选框，**默认关闭**。
- 开启后：刮削成功的**街机**游戏会把 ScreenScraper 返回的完整信息缓存到本地，导出时可据此**自动找齐父 ROM**（clone 依赖）。
- ⚠️ 代价：会**占用部分请求额度**。只有玩街机、需要处理父子 ROM 关系时才建议开。

> 软件首次运行会弹一次窗问你要不要开这个（见 `03`、《引导节点梳理》E3/N23）；当时没想清楚可以之后来这里改。

---

## 17.7 游戏列表展示设置

- **游戏列表图标字段**：决定游戏列表里每行显示哪种图。可选项很多（约 20 种），常见的：

  | 选项 | 含义 |
  |---|---|
  | 封面图 (image) | 默认封面 |
  | 轮盘图标 (wheel / wheel-carbon / wheel-steel) | 游戏标志 |
  | 包装盒 (box-2D / box-2D-back / box-3D / box-2D-side) | 盒图正/背/立体/侧 |
  | 截图 (ss) / 标题画面 (sstitle) | 游戏画面 |
  | 横幅图 (banner) / 海报 (poster) / 粉丝艺术图 (fanart) | 宣传图 |
  | 其它 | logo、thumbnail、bezel、panel、steam、steamgrid 等 |

- 设置后**需刷新页面生效**。
- ⚠️ 注意：如果某个游戏**没有所选类型的媒体文件**，图标位置会**显示空白**。所以选了 wheel 但没下载 wheel，就会一片空。

---

## 17.8 数据库备份 ⚠️（重点，含危险操作）

这一块管理你的数据安全，三个按钮后果差别很大：

| 按钮 | 作用 | 风险 |
|---|---|---|
| **备份数据库** | 把当前数据打包备份（可在下方备份列表选择/管理） | 🟢 安全，建议常做 |
| **恢复数据库** | 用某个备份**覆盖**当前数据（会删除现有表再导入） | 🟠 高——当前数据被替换 |
| **执行初始化** | **重建表结构并清空所有数据** | 🔴 极高——**不可逆**，全部数据没了 |

页面已明确标注：

> 执行数据库初始化操作将重建表结构并清空所有数据。**此操作不可逆，请谨慎执行！**

**使用建议**：
- 做任何有风险的大操作前（平台合并、批量删除、恢复、初始化），**先点"备份数据库"**。
- **恢复**前想清楚：它会用备份覆盖现在的数据，现在比备份新的改动会丢。
- **初始化**基本等于"恢复出厂设置"，只在确实要清空重来时才用，且**务必先备份**。

> 这三个操作（尤其初始化/恢复）是我们记录在案的高优先级引导点（《引导节点梳理》N20）：将来可能加强确认（如输入确认词）以防误点。

---

## 17.9 典型用法

- **第一次用**：填 ScreenScraper 账号 → 测试连接 → 获取系统列表（刮削前提）。
- **想换个心情**：切主题包 / 调音效 / 换列表图标字段。
- **做大动作前**：先备份数据库。
- **搞砸了想回退**：从备份列表恢复（先确认备份是想要的版本）。
- **多语言用户**：切语言 → 刷新。
