# 04 · 端到端流程

> 本章不讲单个功能细节，而是带你**从头到尾走一遍完整主线**，让你理解"这些功能是怎么串起来用的"。每个环节都标注了对应的详解章节，需要深入时再跳过去看。

---

## 4.1 一张图看懂主线

```
 ① 准备          ② 导入           ③ 绑定系统         ④ 刮削信息
 ROM/数据   →   进入平台    →   平台↔ScreenScraper  →  补全文字资料
                                                        ↓
 ⑦ 导出          ⑥ 编辑整理        ⑤ 下载媒体
 给前端用   ←   修正/翻译/合并  ←   补全图片视频
```

七个环节：
1. **准备**：备好 ROM 或已有前端的数据文件。
2. **导入**：把数据读进软件，形成"平台 + 游戏列表"。
3. **绑定系统**：告诉软件这个平台对应 ScreenScraper 的哪个标准系统。
4. **刮削信息**：自动补全游戏的名称、简介、发行商、类型、日期等文字资料。
5. **下载媒体**：自动下载封面、截图、视频等图片/视频。
6. **编辑整理**：手动修正错误、翻译、合并多碟游戏、批量调整。
7. **导出**：按目标前端要求的格式导出，直接给模拟器用。

下面逐个环节说。

---

## ① 准备：先有 ROM 或数据

你需要有下面二者之一（或都有）：

- **一批 ROM 文件**：放在某个目录里（Docker 部署时通常是挂载进去的 `roms` 目录）。
- **已有前端的数据文件**：比如你之前用 Pegasus / ES-DE / RetroBat 生成的游戏列表文件（`metadata.pegasus.txt`、`gamelist.xml` 等）和媒体文件夹。

同时确认：ScreenScraper 账号已在 **系统设置** 里配好（否则第 ④⑤ 步没法自动刮削）。→ 见 `02 快速上手` 第 3 步。

---

## ② 导入：把数据读进来

**入口**：侧边栏 **数据导入** 📥 → 详见 `09 数据导入`

两种典型导入方式：

- **模板导入**：你已有前端数据文件，选对应模板（Pegasus / ES-DE / RetroBat / EmuELEC 等），软件按模板规则解析文件，把游戏和媒体路径读进来。
- **无数据文件导入（扫描 ROM）**：你只有 ROM、没有数据文件，直接扫描 ROM 目录，软件为每个 ROM 建立游戏条目（资料先空着，等刮削补全）。

导入时可能会：
- 弹出**模板变量**填写框（如 ROM 文件夹名、URL 前缀），按说明填。
- 触发**媒体发现**（mediaDiscovery），自动在磁盘上按规则给游戏匹配已有的图片/视频。

**产出**：数据库里新增了"平台"和平台下的"游戏"。去 **平台管理** 🎮 就能看到新平台。

---

## ③ 绑定系统：平台和 ScreenScraper 系统对上号

**入口**：**平台管理** → 编辑平台 → 选择刮削系统；或直接打开平台的游戏列表触发引导 → 详见 `06 平台管理`

**为什么必须做**：ScreenScraper 按"标准系统"（PS1、Saturn、MAME…）组织数据。你的平台要**绑定**一个系统，软件才知道去数据库里按哪个主机查资料。**没绑定就没法自动刮削。**

**方便的地方**：当你打开一个**还没绑定系统**的平台的游戏列表时，软件会**自动弹出"系统匹配引导"**，根据平台文件夹名、扩展名等智能推荐最可能的几个系统，你点一下就能绑定；也可以"我自己选"或"暂不绑定"。绑定后还能勾选"记住此映射"，下次同名文件夹自动命中。

---

## ④ 刮削信息：补全文字资料

**入口**：平台管理 → 平台行的"刮削"按钮；或游戏列表里批量刮削 → 详见 `11 自动刮削`

刮削会连接 ScreenScraper，为每个游戏查回：名称、简介、发行商、开发者、发行日期、类型、玩家数、评分等**文字资料**。

**关键点（很多人踩坑）**：从 1.2 起，"刮削"分成**两个独立步骤**——
- 这一步只刮**信息（文字）**。
- 图片/视频是**下一步单独的"媒体下载"**。

所以刮完信息发现"怎么没封面"是正常的，媒体要单独下载（见 ⑤）。

刮削任务进入后台队列，去 **任务管理** 📋 看进度；完成后右上角**通知铃铛**会提醒。

---

## ⑤ 下载媒体：补全图片视频

**入口**：侧边栏 **媒体下载** 🖼️，或任务管理里的媒体下载面板 → 详见 `12 媒体文件管理`

这一步把封面（box-2D）、截图（ss）、视频（video）、标志（wheel）、背景图（fanart）等**媒体文件**下载下来。ScreenScraper 有 **50 种媒体类型**，你可以只选需要的几种（常用：封面 + 截图）。

媒体文件下载到 `data/scraper/games/{系统}/{游戏}/` 下，数据库里记录相对路径。

**注意**：
- 媒体下载有并发限制（默认 3 个）和限流保护，速度慢是正常的，别急。
- 遇到 404 或限流，软件会自动退避重试。
- 下载任务同样在 **任务管理** 里可暂停/恢复/停止/重试。

---

## ⑥ 编辑整理：按需修正

**入口**：平台管理 → 点平台 → **游戏列表** → 点游戏 → **游戏编辑** → 详见 `07 游戏列表管理`、`08 游戏编辑`

刮削回来的资料不一定 100% 准确，这一步用来修正和增强：

- **单个编辑**：进游戏编辑页，改名称/描述/类型等，4 个 Tab（基本信息 / 元数据 / 媒体管理 / 媒体预览）。自动刮削没匹配上的游戏，可用"搜索游戏"手动从 ScreenScraper 找。
- **批量操作**：在游戏列表勾选多个游戏，批量修改字段、批量翻译、批量重新刮削、切换译文、合盘（多碟合成 m3u）等。
- **状态一目了然**：游戏列表用红/黄/绿标记数据完整度（红=无信息，黄=部分缺失，绿=完整），方便你优先处理红色和黄色的。
- **翻译**：可把资料翻译成目标语言（见 `17`）。

> ⚠️ 合盘会删除原独立条目、且可能影响 ROMset 完整性，操作前想清楚。

---

## ⑦ 导出：给前端使用

**入口**：侧边栏 **数据导出** 📤 → 详见 `10 数据导出`

整理好后，把数据导出成目标前端能用的格式：

1. 选要导出的平台（可单个或批量）。
2. 选目标前端模板（Pegasus / ES-DE / RetroBat 等）。
3. 勾选导出内容：**游戏文件（ROM）/ 媒体文件 / 数据文件**。
4. 指定输出目录。
5. 导出前软件会做**预检（preflight）**，给出建议（直接导出 / 拆分 / 建议整目录），按提示处理。
6. 点导出，任务进入队列，去 **任务管理** 看进度。

**产出**：输出目录里生成数据文件（如 `gamelist.xml`、`metadata.pegasus.txt`）+ 归置好的 ROM 和媒体，直接拷给你的前端就能用。

---

## 4.2 贯穿全程的两个"看板"

无论你走到哪一步，这两个地方随时帮你掌握全局：

- **首页仪表盘** 🏠（详见 `05`）：看总平台数、总游戏数、刮削覆盖率、刮削分级（已刮削/原始数据/低质量/原始ROM）、系统状态、运行中任务。
- **任务管理** 📋（详见 `14`）：看所有后台任务的状态和进度，能停止、取消、删除、重试，也能控制媒体下载。

---

## 4.3 一个完整例子（串起来）

假设你有一批世嘉 Saturn 的 ROM，想做成 ES-DE 能用的图文游戏库：

1. **准备**：ROM 放在 `roms/saturn/`，配好 ScreenScraper 账号。
2. **导入**：数据导入 → 选"扫描 ROM 目录"或 ES-DE 模板 → 生成一个平台。
3. **绑定**：打开该平台游戏列表 → 自动弹匹配引导 → 选 "Sega Saturn" 绑定（可勾"记住此映射"）。
4. **刮削信息**：平台管理 → 该平台 → 刮削 → 开始，等任务跑完。
5. **下载媒体**：媒体下载 → 选封面+截图 → 开始下载。
6. **编辑**：游戏列表里把标红/标黄的处理一下，个别没匹配的手动搜索；需要中文就翻译。
7. **导出**：数据导出 → 选该平台 → ES-DE 模板 → 勾选 ROM+媒体+数据 → 指定目录 → 导出。
8. 把输出目录拷到 ES-DE，开机就能看到图文并茂的游戏列表了。
